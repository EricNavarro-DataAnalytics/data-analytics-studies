# Select
- Seleciona uma Coluna ou mais.

# From
- Indica de qual tabela pertence a Coluna Selecionada.

<details>
<summary><b>Selecionando Tudo</b></summary>

```sql
SELECT 
    *
FROM doces
```

</details>

<details>
<summary><b>Selecionando Colunas específicas</b></summary>

```sql
SELECT 
    preco,
    tipo,
    marca
FROM doces
```

</details>
